## 🚀 Featured Open-Source Project

### 🪪 id_doc_kit
A Flutter/Dart package for **Indian ID document validation** used in **KYC & onboarding workflows**.

**Supports:**
- Aadhaar (checksum)
- PAN
- GSTIN
- Driving License (strict + fallback)
- Voter ID
- Passport
- PIN Code, Phone, Email

**Highlights:**
- Structured validation results
- Confidence scoring (risk-aware)
- Metadata extraction
- UI-friendly widgets
